# Linux Server-Setup
***Introduction***

In this lab the goal is to install multiple linux servers on a Virtual Machine or VM.
A Virtual Machine is a virtual machine running inside a host machine or Computer.
The virtual machine also known as guess machine has its own dedicated cpt, ram and disk space and you can install multiple VM 
on the Host machine. The Virtual Machine  used in this lab is the Oracle VirtualBox because it was previusly intalled and updated
on the host machine. The KVM(Kernel-based Virtual Machine) used in Linux environments is also an option.  
This document focust on downloading steps by steps descriptions on downloading and intalling the CentOS server without the GUI and
the Obuntu server. The steps also cover in detail how to set up internet conectivity and share files between servers.
